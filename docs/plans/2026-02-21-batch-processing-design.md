# 批量处理功能 GUI 设计文档

**日期**: 2026-02-21
**功能**: GUI 批量处理图像/视频去水印

---

## 1. 功能概述

在现有 GUI 中添加批量处理功能，支持：
- **多文件模式**: 一次选择多个文件，使用同一个 ROI 区域处理
- **文件夹模式**: 选择文件夹，自动处理文件夹内所有支持的文件

## 3. 数据结构

### 批量任务

```python
@dataclass
class BatchTask:
    files: List[Path]           # 要处理的文件列表
    roi: Tuple[int,int,int,int] # ROI 区域
    algorithm: str              # 修复算法
    radius: int                # 修复半径
    quality: int               # 输出质量
    max_workers: int           # 最大并发数
    use_adaptive: bool         # 是否自适应调度
    output_dir: str            # 输出目录
```

### 处理结果

```python
@dataclass
class BatchResult:
    total: int              # 总数
    success: int            # 成功数
    failed: int             # 失败数
    output_files: List[Path] # 输出的文件列表
    errors: List[str]       # 错误信息列表
```

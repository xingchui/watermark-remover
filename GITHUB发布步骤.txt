================================================================================
                    GitHub 发布步骤指南
================================================================================

一、设置 Git 用户信息（首次使用必须执行）
================================================================================

打开终端，执行以下命令：

    git config --global user.email "你的邮箱@example.com"
    git config --global user.name "你的名字"

示例：
    git config --global user.email "wangwu@163.com"
    git config --global user.name "王五"

注意：请将引号内的内容替换为你自己的邮箱和名字


二、提交代码到本地仓库
================================================================================

进入项目目录并执行提交：

    cd E:\op\op3\watermark_remover
    git add .
    git commit -m "Initial commit: 水印去除工具 v1.0"


三、创建 GitHub 仓库
================================================================================

1. 打开浏览器，访问 https://github.com/new

2. 填写仓库信息：
   - Repository name: watermark-remover
   - Description: 基于OpenCV和PyQt6的本地离线水印去除工具
   - 选择 Public（公开）或 Private（私有）
   - 不要勾选 "Add a README file"（已有）
   - 不要勾选 "Add .gitignore"（已有）
   - 不要勾选 "Choose a license"（已有）

3. 点击 "Create repository"

4. 创建成功后，复制仓库地址，格式类似：
   https://github.com/你的用户名/watermark-remover.git


四、推送到 GitHub
================================================================================

在终端执行（替换 yourusername 为你的 GitHub 用户名）：

    git remote add origin https://github.com/yourusername/watermark-remover.git
    git push -u origin master

示例（假设用户名是 wangwu）：
    git remote add origin https://github.com/wangwu/watermark-remover.git
    git push -u origin master


五、创建 Release（发布版本）
================================================================================

方法一：网页手动发布（推荐）

1. 打开 GitHub 仓库页面
2. 点击右侧 "Releases" → "Create a new release"
3. 填写信息：
   - Tag version: 输入 v1.0，点击 "Create new tag: v1.0"
   - Release title: 水印去除工具 v1.0
   - Description: 填写发布说明
4. 点击 "Attach files" 上传 exe 文件：
   - 文件路径：E:\op\op3\watermark_remover\dist\watermark_remover_v1.0_dist\watermark_remover_v1.0.exe
5. 点击 "Publish release"

方法二：推送标签自动构建

    git tag -a v1.0 -m "Release version 1.0"
    git push origin v1.0


六、常见问题
================================================================================

Q: 推送时提示权限错误？
A: 需要使用 Personal Access Token 作为密码，或配置 SSH 密钥

Q: 分支名称是 main 还是 master？
A: 使用 git branch 查看当前分支名称，如果显示 main 则用：
   git push -u origin main
